# Day 2 — 2026-10-26

## Topic: Valid Anagram (Python)

**Problem:** Given two strings `s` and `t`, return `True` if `t` is an anagram of
`s` — same characters, same counts, in any order.

## What I learned

- The same hash map idea from Day 1's Two Sum applies, but to **character
  counts** instead of indices.
- Count every character of `s` into a dict, then walk through `t` and decrement.
  If every count lands back at zero, the strings are anagrams.
- Early exit: different lengths can never be anagrams, so check that first —
  it's a free **O(1)** shortcut that skips the real work entirely.
- Time: **O(n)** — each string is scanned once. Space: **O(k)** — one dict entry
  per distinct character (bounded by the alphabet size).

## Code

See [`valid_anagram.py`](valid_anagram.py) in this folder, with tests.

```python
def is_anagram(s, t):
    if len(s) != len(t):
        return False
    counts = {}
    for ch in s:
        counts[ch] = counts.get(ch, 0) + 1
    for ch in t:
        if ch not in counts:
            return False
        counts[ch] -= 1
        if counts[ch] < 0:
            return False
    return True
```

## Example

`is_anagram("listen", "silent")` → `True`, and `is_anagram("rat", "car")` →
`False`.
