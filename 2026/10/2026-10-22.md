# Day 1 — 2026-10-22

## Topic: Two Sum (Python)

**Problem:** Given a list of numbers and a target, return the indices of the two
numbers that add up to the target. Assume exactly one solution, and the same
element can't be used twice.

## What I learned

- The brute-force approach checks every pair: **O(n²)** time, O(1) extra space.
- The better approach makes **one pass** with a hash map (a Python `dict`) that
  remembers each value I've already seen and its index.
- For each number `x`, the value I actually need is `target - x` — the
  *complement*. If the complement is already in the map, I'm done.
- That trades a little memory — **O(n)** space — for **O(n)** time.

## Code

See [`two_sum.py`](two_sum.py) in this folder: both approaches, with tests.

```python
def two_sum(nums, target):
    seen = {}                       # value -> index
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:
            return [seen[need], i]
        seen[x] = i
```

## Example

`two_sum([2, 7, 11, 15], 9)` → `[0, 1]`, because 2 + 7 = 9.
